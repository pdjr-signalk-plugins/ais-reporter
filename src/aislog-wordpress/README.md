# postie-ais-log-handler

`postie-ais-log-handler` is a collection of
[WordPress](https://wordpress.org/)
plugins which renders blog
posts from email messages generated by
[ais-log-uploader](https://github.com/pdjr-signalk-plugins/ais-reporter/tree/main/src/ais-log-uploader).

The plugin collection includes `postie-ais-log-handler.php` which
operates as a filter for the WordPress
[Postie](https://wordpress.org/plugins/postie/)
plugin which is itself responsible for all email handling and
WordPress integration.

The remaining elements of the collection are an extensible set of
scripts which render various types of email attachments.

## Installation

`postie-ais-log-handler.php` implements the final stage of an ais log
publishing process (see
[Publishing AIS logs in WordPress]()
for an overview).

You can complete the following installation at any time, but earlier
stages of the publishing process must be in place and working before
this final stage can operate as intended.

If necessary, install the WordPress Postie plugin and configure it to
retrieve and process messages from the dedicated email account to which
`ais-log-uploader` sends its daily ais log.
Configure Postie so that it scans the email account once every hour.

Login to your WordPress site host, download the git repository and copy
`postie-ais-log-handler.php` to your WordPress site.
The following example assumes WordPress is installed at
`/srv/www/wordpress` and runs as user `www-data` - adjust as necessary.

```bash
cd ~
git clone https://github.com/pdjr-signalk-plugins/ais-reporter.git
sudo cp ais-reporter/src/postie-ais-log-handler/*.php /srv/www/wordpress/wp-content/mu-plugins/
sudo chown www-data:www-data /srv/www/wordpress/wp-content/mu-plugins/aislog-*.php
sudo chmod 755 /srv/www/wordpress/wp-content/mu-plugins/aislog-*.php
```

Delete the git repository.

```bash
rm -r ais-reporter
```
